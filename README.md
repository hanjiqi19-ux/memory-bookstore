# 记忆书店

面向长辈的记忆整理网站，支持手机、平板和电脑。功能包括回忆书写、照片、录音、私人话题，以及邮箱注册登录、个人资料和账号云端存储。

## 打开网站

入口为 index.html，无需构建。部署到 GitHub Pages 时选择 main 分支和根目录。

## 启用用户账号

默认保留游客模式。账号服务需要 Supabase 项目，完整步骤见 [账号配置说明](账号配置说明.md)。填写 auth-config.js 的项目地址和公开密钥，并执行 supabase-schema.sql 后才能使用真实注册、登录和云端存储。

严禁提交 service_role、secret key 或数据库密码。密码由 Supabase Auth 管理，数据库使用行级权限隔离各用户记录。

游客数据仅保存在当前浏览器；登录后的数据保存在该用户云端账号。游客记录需主动导入，不会自动上传。话题目前为私人记录，不是公共论坛。

请定期导出回忆备份。未配置后端时，账号入口会明确提示服务尚未启用。
